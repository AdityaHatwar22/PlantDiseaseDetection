#  Plant Disease Detection using Deep Learning

##  Overview

This project is a **Computer Vision based Plant Disease Detection System** that classifies plant leaves as **Healthy ** or **Diseased ** using Deep Learning.

It helps farmers and researchers to quickly identify plant diseases and take necessary actions.

---

## Features

*  Image-based plant disease detection
*  Deep Learning model using TensorFlow/Keras
*  Fast and accurate predictions
*  Trained on plant leaf dataset
*  Simple and easy-to-use code

---

##  Tech Stack

* Python 
* TensorFlow / Keras
* OpenCV
* NumPy
* Matplotlib

##  How to Run the Project

### 1️ Clone the repository

```
git clone https://github.com/AdityaHatwar22/Plant-Disease-Detection.git
cd Plant-Disease-Detection
```

### 2️ Install dependencies

```
pip install tensorflow opencv-python numpy matplotlib
```

### 3️ Train the model

```
python train.py
```

### 4️ Test the model

```
python predict.py
```
